# DietPlanner

**DietPlanner** — локальний Windows-застосунок для планування харчування, контролю калорій і макронутрієнтів, ведення каталогу продуктів та відстеження фактично спожитої їжі.

Застосунок працює без окремого сервера: дані зберігаються локально у SQLite, а інтернет потрібен лише для пошуку продуктів через Open Food Facts і перекладу пошукових запитів.

## Можливості

- локальна реєстрація, вхід, вихід і автоматичне відновлення сесії;
- профіль користувача: дата народження, стать, зріст, маса, рівень активності, мета та обмеження харчування;
- розрахунок базового обміну речовин, добової калорійності та цільових показників білків, жирів і вуглеводів;
- генерація раціону на один день або на сім днів;
- від одного до восьми прийомів їжі на день із варіативним підбором продуктів і страв;
- урахування дієтичних обмежень та алергенів;
- особистий і загальний каталог категорій, продуктів та страв з інгредієнтами;
- пошук, фільтрація, сортування та редагування елементів каталогу;
- імпорт початкових категорій, продуктів і страв із JSON-файлів;
- запис фактично спожитих продуктів і позначення виконаних пунктів плану;
- контроль водного балансу;
- статистика за день, тиждень і місяць;
- історія планів, журнал дій і скасування останньої операції;
- експорт харчового звіту у текстовий файл;
- пошук продуктів у базі Open Food Facts;
- українська та англійська локалізації інтерфейсу;
- адміністративна панель для керування користувачами, журналами та системним оголошенням.

> Розрахунки мають інформаційний характер і не замінюють консультацію лікаря або дієтолога.

## Технології

- **C# / .NET 10**;
- **WPF** і XAML для desktop-інтерфейсу;
- **MVVM** на основі CommunityToolkit.Mvvm;
- **Entity Framework Core 9 + SQLite** для локального зберігання;
- **Microsoft.Extensions.DependencyInjection** для впровадження залежностей;
- **BCrypt.Net-Next** для хешування паролів;
- **Open Food Facts API** для пошуку продуктів;
- **MyMemory API** для допоміжного перекладу пошукових запитів;
- **xUnit v3** для автоматизованих тестів.

Основний застосунок збирається як `net10.0-windows` із типом `WinExe`. Окремого вебсервера немає.

### Як працює застосунок

Під час запуску `App.OnStartup` налаштовує контейнер залежностей, створює локальну SQLite-базу через `AppDbContext`, запускає `DbInitializer` і відкриває головне вікно. `AuthenticationService` намагається відновити локальну сесію, після чого `NavigationService` відкриває автентифікацію або Dashboard.

Сервіси працюють із моделями `User`, `Product`, `Dish`, `NutritionPlan`, `MealIntake` і `ActionRecord`. `PlanService` отримує дані каталогу, перевіряє обмеження через `RestrictionService`, формує прийоми їжі та оптимізує порції під цільові калорії й КБЖВ. `NutritionCalculator` використовує профіль користувача для розрахунку добових цілей.

`AppPaths` зберігає прикладні файли в `%APPDATA%\\DietPlanner`, а початкові категорії, продукти й страви імпортуються з `Data/*.json` під час першого запуску.

## Запуск

### Visual Studio

1. Клонуйте репозиторій.
2. Відкрийте `DietPlanner.sln`.
3. Дочекайтеся відновлення NuGet-пакетів.
4. Запустіть профіль `Unpackaged` або натисніть **F5**.

### Командний рядок

```powershell
git clone https://github.com/Xydik1otto/DietPlaner_NoAi.git
cd DietPlaner_NoAi
dotnet restore .\DietPlanner.sln
dotnet build .\DietPlanner.sln
dotnet run --project .\DietPlanner.csproj
```

## Тести

Тести розміщені в `DietPlanner.Tests/` і перевіряють моделі, автентифікацію, авторизацію, каталог, прийоми їжі, розрахунки, генерацію планів, обмеження, пошук, сортування, статистику та валідацію.

```powershell
dotnet test .\DietPlanner.sln
```

## Дані користувача

Після першого запуску автоматично створюються:

```text
%APPDATA%\\DietPlanner\\dietplanner.db
%APPDATA%\\DietPlanner\\logs\\
%APPDATA%\\DietPlanner\\reports\\
%APPDATA%\\DietPlanner\\report.txt
```

Файли `Data/categories.json`, `Data/products.json` і `Data/dishes.json` копіюються до каталогу збірки та використовуються для початкового наповнення каталогу.

## Локалізація

Рядки інтерфейсу зберігаються у `Resources/Strings.uk-UA.xaml` та `Resources/Strings.en-US.xaml`. Мову можна змінити в налаштуваннях застосунку; українська локалізація є основною для цього репозиторію.

## Безпека та конфіденційність

Паролі зберігаються лише у вигляді BCrypt-хешів. Профіль, база даних, журнали й звіти зберігаються локально. Не передавайте файл `dietplanner.db`, якщо він містить персональні дані.
